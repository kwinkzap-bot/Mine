ENTRY CRITERIA (What triggers a buy order)
================================================================================

CANDLE OPEN MODE:
✓ Day open validation (if opened above reference, wait for close below)
✓ Low < reference_high (candle touched the level)
✓ Close > (reference_high + 5) (closed above with buffer)
✓ |Close - Reference_high| < 20 (within 20-point range)

HIGH CROSS MODE:
✓ High + 5 crosses above reference level
✓ Low < reference_high (price touched the level)
✓ Close > (reference_high + 5) (closed above with buffer)
✓ |Close - Reference_high| < 20 (within 20-point range)
✓ Plus all day-open validations from candle_open

EXIT CRITERIA (Automatically detected):
✓ SL Hit: Price closes below SL (automatic stop loss)
✓ Target Hit: Price closes above target (automatic profit)
✓ Manual: Can be triggered via close_trade()

================================================================================
RISK MANAGEMENT
================================================================================

STOP LOSS LOGIC:
- If (Entry - Reference) > 10: SL = Reference - 10
- If (Entry - Reference) ≤ 10: SL = Reference - 20

PROFIT TARGET (1:2 ratio):
- Target = Entry + 2 * (Entry - SL)

EXAMPLE:
- Reference High: 24500
- Entry: 24515 (price crossed above + 5)
- Price Diff: 24515 - 24500 = 15 (> 10)
- SL = 24500 - 10 = 24490
- Risk = 24515 - 24490 = 25 points
- Target = 24515 + (2 * 25) = 24565
- Ratio: Risk 25 : Reward 50 = 1:2

PULLBACK PROTECTION (1:2-trail mode):
- SL maintains minimum floor at entry_price
- During pullback: SL stays at entry_price (break-even)
- After recovery: SL starts trailing upward
